# Creator Studio Analytics

A Streamlit concept dashboard that makes creator channel metrics easier to scan and act on.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Data

All displayed channel metrics are synthetic demo data. The project does not connect to or represent a real YouTube account.

## Deploy

Create an app in [Streamlit Community Cloud](https://share.streamlit.io/) using `app.py` as the entry point.
